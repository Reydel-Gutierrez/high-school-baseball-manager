# UI concepts (October 2026)

Target look for the redesign: one left rail (Home, Team, Season, League, Scout, Office),
one gold CONTINUE button, team-branded banners, two text sizes per card, and only the
important numbers shown big. Rendered from HTML mockups with real team art and engine
headshots; numbers in them are illustrative.

| File | Page |
|---|---|
| 01_home | Home dashboard |
| 02–07 | Team: roster, player profile, depth chart, pitching staff, training, medical |
| 08–11 | Season: calendar, game day, tryouts, graduation |
| 12–16 | League: districts, standings, leaders, rankings & awards, news |
| 17 | Scout: player search |
| 18–21 | Office: career & mail, board & goals, budget & sponsors, job market |
| 22–23 | Main menu, coach creator |
